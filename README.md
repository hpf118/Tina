# Tina — L&D Toolkit

Instructional-design assets for corporate learning & development.

- **[`template-bank/`](template-bank/)** — the Training Slide Template Bank: a PowerPoint deck of 12 reusable slide layouts for adult training, organized by knowledge type (logical/structural, categorical, concrete/visual). See [`template-bank/README.md`](template-bank/README.md) for the slide list and how to rebuild the deck.
- **[`storyboard-prompt/`](storyboard-prompt/)** — the Shareable Storyboard Generator Master Prompt. `Storyboard-Generator-Master-Prompt-v3.2.md` / `.docx` is the current consolidated prompt (one layer, contradictions resolved, content-quality rules added); `CHANGELOG-v3.2.md` records every decision and maps each v3.1 section to its v3.2 home; `REVIEW-master-prompt-v3.1.md` is the audit that motivated the rewrite.
