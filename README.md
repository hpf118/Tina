# Tina — L&D Toolkit

Instructional-design assets for corporate learning & development.

- **[`template-bank/`](template-bank/)** — the Training Slide Template Bank: a PowerPoint deck of 12 reusable slide layouts for adult training, organized by knowledge type (logical/structural, categorical, concrete/visual). See [`template-bank/README.md`](template-bank/README.md) for the slide list and how to rebuild the deck.
- **[`storyboard-prompt/presentation/`](storyboard-prompt/presentation/)** — the ten-minute visitor presentation "Transforming Learning Design at Scale" (`.pptx` with speaker notes) and its script with a timing plan (`Presentation-Script.md` / `.docx`).
- **[`storyboard-prompt/`](storyboard-prompt/)** — the Shareable Storyboard Generator Master Prompt. `Storyboard-Generator-Master-Prompt-v3.3.md` / `.docx` is the current prompt in CRAFT structure (Context, Role, Action, Format, Target audience and Tone), with every v3.2 rule plus the reviewer-readability rules; `v3.2` is the first consolidated single-layer version; `CHANGELOG-v3.2.md` records every decision, every rule added, and where each earlier section went; `REVIEW-master-prompt-v3.1.md` is the audit that started it.
